
### 自动垃圾回收

考虑某时刻 $t$ 系统中所有对象构成的集合 $O_t = \{o_1, o_2, ..., o_n\}$ 以及由对象间持有关系构成的集合 $R_t = \{ u \rightarrow v | u, v \in O_t\}$，因此可用图表示对象之间的依赖关系。若某对象 $o$ 在 $O_{t}$ 中与任意对象都没有边，则可将其视作垃圾，因为从 $t$ 时刻后不再不再有对象可达它，将其释放是安全的。假设 $G = (O_t, R_t)$ 是一个有向无环图（DAG），可证明系统中的所有对象都能被正常回收。需特别说明的是，系统中存在一个或多个对象会被系统本身持有，如堆栈或局部变量等，在系统退出时会释放所持有的对象。









































### 引用计数

如 C 语言中，堆分配的内存需要人工编写代码释放，而步入面向对象系统，自动垃圾回收成为标准配套设施。自动垃圾回收至少需要考虑两个问题，一是识别什么是垃圾，二是何时回收它们。引用计数是一种简单且有效的自动垃圾回收实现方案，其为每个对象都绑定一个计数器状态，在创建对象时初始化为 *1*。对象间允许互相持有，即具有对方的强引用。当一个对象希望持有另一个对象时，需将被引用对象的引用计数器加 1，反之若不再需要它时，则将其引用计数器减 1。当某个对象的引用计数器变为 0 时，表明该对象不在被其他对象需要，即可当作垃圾对象，也可立即回收其占用内存。
