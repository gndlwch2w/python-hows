## 类

区别于面向过程的编程范式，@@OOP@@ 系统中将程序开发抽象出类和实例两个主体。类（Class）定义数据的形式以及对数据的操作，而对象（Object）是类的实例，即具有实际数据的实体。

* 程序系统由不同对象之间的协作进行运转，如消息传递机制通过接受消息、处理消息、传出消息或使用其他实例的方法来实现功能。

* 类之间允许继承，从而派生出更加具体化的子类。

这种机制带来诸多益处，如**抽象性**提供了简化复杂的现实问题的途径，即为具体问题找到最恰当的类定义，并且可以在最恰当的继承级别解释问题。**封装性**通过限制只有特定类的对象可以访问这一特定类的成员，取而代之利用界面实现消息的传入传出，从而封闭具体细节，便于更复杂的调用与协作。
